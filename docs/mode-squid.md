# 鱿鱼模式策略指南

> **模式特征**: 渐进淘汰赛制，每轮淘汰垫底玩家，最终存活者获胜

---

## 1. 模式定义

鱿鱼模式（Squid Game Mode）是一种生存型淘汰赛制，核心规则：

```text
每轮所有玩家独立决策
↓
轮末计算排名
↓
垫底 N 名玩家淘汰
↓
幸存者进入下一轮
↓
最终 1 名获胜者
```

与标准德州扑克的关键区别：

| 维度 | 标准 Cash/MTT | 鱿鱼模式 |
|------|--------------|---------|
| 目标 | 最大化 EV/筹码 | **活下来** |
| 风险偏好 | EV 驱动 | **生存驱动** |
| 淘汰机制 | 输光筹码 | **排名垫底** |
| 最优策略 | 剥削性决策 | **相对排名最大化** |

---

## 2. 数学分析

### 2.1 生存概率的数学模型

设当前轮有 \(N\) 名玩家，淘汰 \(K\) 名（通常 \(K = 1\) 或 2）。Hero 活到下一轮的概率为：

\[
P_{\text{survive}} = P(\text{Rank}_{\text{Hero}} \leq N - K)
\]

这与标准扑克的本质区别在于：**不是你赢多少筹码，而是你比别人多多少。**

### 2.2 相对 EV 的引入

标准 EV：

\[
EV_{\text{standard}} = \sum_{o} P(o) \cdot \Delta_{\text{chips}}(o)
\]

鱿鱼模式的目标函数应改写为**相对于中位数玩家的超额收益**：

\[
EV_{\text{squid}} = \sum_{o} P(o) \cdot \left[ \Delta_{\text{chips}}(o) - \mathbb{E}[\Delta_{\text{median}}] \right]
\]

其中 \(\mathbb{E}[\Delta_{\text{median}}]\) 是本轮所有玩家的预期中位收益。

### 2.3 关键推论：方差与生存的权衡

设 Hero 有两个选择：

| 选择 | 预期收益 | 方差 | 排名低于中位数的概率 |
|------|---------|------|-------------------|
| A: 激进打法 | +8bb | 高 (σ²=200) | 45% |
| B: 保守打法 | +3bb | 低 (σ²=20) | 25% |

在标准 Cash 中，A 严格优于 B（EV 更高）。

在鱿鱼模式中，设淘汰线为后 20%：

\[
P_{\text{A eliminated}} \approx 0.45 \times 0.20 = 9\%
\]
\[
P_{\text{B eliminated}} \approx 0.25 \times 0.20 = 5\%
\]

选择 B 的生存概率显著更高。**鱿鱼模式中 EV 不是唯一目标，存在 EV-生存的边界条件。**

## 3. 核心策略调整

### 3.1 筹码领先时的策略

当 Hero 处于筹码领先位置时：

```text
策略原则：压榨中等筹码，避开极端短码

✅ 对中等筹码（30-60bb）：高频施压，迫使他们进入被动防守
✅ 对极短码（< 10bb）：少接触，避免翻倍对手
❌ 对同等大筹码：避免中大型底池对抗，除非牌力绝对领先
```

**数学理由**：
- 中等筹码玩家在鱿鱼模式中处于"恐惧区"——他们最怕被淘汰
- Fold Equity 对中等筹码最高
- 帮短码翻倍 = 减少自己相对排名，不符合生存目标

### 3.2 筹码落后时的策略

```text
策略原则：只在有力位置、有力手牌时出手

✅ 后位（BTN/CO），有强牌 → 打价值
✅ 大盲位，有好赔率 → 防守
❌ 前位，中等牌 → 直接弃
❌ 诈唬频度大幅降低
```

**数学理由**：

设 Hero 筹码为 \(C_h\)，淘汰线为 \(C_{\text{cut}}\)。当 \(C_h < 1.2 \times C_{\text{cut}}\) 时，每手牌的"淘汰风险溢价"急剧上升。

设标准 Call 的 EV 为 +1.5bb，但被淘汰的概率增加 3%。若淘汰意味着失去未来所有轮次的 EV（记为 \(V_{\text{future}}\)），则调整后的 EV：

\[
EV_{\text{adjusted}} = 1.5 - 0.03 \times V_{\text{future}}
\]

当 \(V_{\text{future}} > 50\text{bb}\) 时，该 Call 的调整后 EV 变为负值。

### 3.3 末位淘汰圈策略

当 Hero 处于淘汰线边缘（排名 ≈ \(N-K\)）时：

```text
激进度：⬆⬆⬆

必须主动出击。因为被动的"等别人犯错"策略
在此位置等于"等死"。
```

**最优操作频率**：

| 位置 | VPIP | PFR | 3-Bet |
|------|------|-----|-------|
| 前位 (UTG) | 8-10% | 8-10% | - |
| 中位 (MP) | 12-15% | 10-12% | 3-5% |
| 后位 (CO/BTN) | 25-35% | 20-25% | 8-12% |
| 小盲 (SB) | 15-20% | 12-15% | 5-8% |

关键：**后位激进，前位极端保守。**

## 4. 筹码深度阶段策略

### 4.1 早期（人数多，淘汰压力小）

策略接近标准 MTT 早期：

```text
- 玩标准范围
- 避免中大型底池对抗领先者
- 利用位置优势积累筹码
- 记录对手倾向（谁是激进型？谁是紧弱型？）
```

### 4.2 中期（人数减半，淘汰压力出现）

```text
- 识别"恐惧型"玩家（中等筹码，打得过紧）
- 对这些玩家高频 CBet（他们 Fold-to-CBet 通常 > 65%）
- 避免与"绝望型"玩家（极端短码）对抗
- 不要在无关紧要的底池中浪费筹码
```

### 4.3 后期（接近淘汰线）

```text
- Push/Fold 模式
- 当 M ≤ 5 时，仅剩 Push 或 Fold 两种选择
- 优先推短码盲注
- 推入时考虑对手的 Call 范围（紧弱玩家 Call 范围极窄）
```

## 5. 常见错误

### 错误 1：以 Cash 心态打鱿鱼

```text
错误思维："这手牌 EV +3bb，必须打"
正确思维："+3bb EV 但方差大，我的淘汰风险是否可接受？"
```

### 错误 2：在安全位置过度保守

```text
当 Hero 排名前 20% 时，适度激进反而是最优策略——
把中等筹码逼入绝境，增加自己存活概率。
```

### 错误 3：忽视对手淘汰动机

```text
中等筹码玩家面对你的下注时，他的决策函数不是
"这手牌是否 +EV"，而是"这手牌是否会让我被淘汰"。

利用这种心理：对中等筹码的 CBet 成功率
比标准模式高出 20-30 个百分点。
```

## 6. 策略总结

| 维度 | 鱿鱼模式 | 标准 Cash |
|------|---------|----------|
| 目标函数 | 生存概率最大化 | EV 最大化 |
| 方差容忍度 | 低 | 高 |
| 边缘+EV 手牌 | 按生存风险决定 | 无条件打 |
| 对短码策略 | 避开 | 可剥削 |
| 对中等筹码策略 | 高频施压 | 根据牌力 |
| 淘汰圈策略 | Push/Fold 二值化 | 无对应概念 |

**一句话总结**：

> 鱿鱼模式的目标不是在每手牌上赢最多筹码，而是让排名比所有淘汰线以上的玩家更高。当你领先时压榨恐惧者，当你落后时只在后位出手，当你在线上时主动出击不等待。
